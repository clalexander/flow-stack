# Basic Example

This is the smallest useful example for FlowStack.

It demonstrates:

- `NavigationStackProvider`
- `NavigationStackViewport`
- two simple screens
- `push`
- `pop`
- default slide transitions

## Run

From the repository root:

```bash
pnpm install
pnpm --filter @flow-stack/example-basic dev
```

The deployed version is available at <https://clalexander.github.io/flow-stack/basic/>.
